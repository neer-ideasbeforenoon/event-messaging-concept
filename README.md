# Messages

Customer-facing Messages screen for an event platform. Customers keep organizer conversations and platform support tickets in two groups on one screen.

Product context, scope, and sample threads are in [PRODUCT.md](./PRODUCT.md).

## Stack

Next.js, Tailwind CSS, and shadcn/ui.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
